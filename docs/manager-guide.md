# Communications Workspace: guide for managers

You only need **a web browser, the workspace link and your own sign-in**. There is nothing to install and no Terminal or command window.

**Use one of these browsers, kept up to date:**

| | Windows | Mac |
| --- | --- | --- |
| Recommended | **Microsoft Edge** (already on every Windows computer) | **Safari** (already on every Mac) |
| Also fine | Google Chrome | Google Chrome |

Not supported: Internet Explorer, or Safari older than version 15.5 (from 2022). If your browser is too old, the workspace shows a message asking you to update. To check Safari's version: **Safari → About Safari**.

> Private pilot: do not put client, resident or donor personal information in requests, comments or documents.

---

## 1. Create your account (once)

Maha sends you a personal invitation link. It works **once** and expires after **3 days**. If it has expired, ask Maha for a new one.

1. Click the link (or copy it into the address bar of Edge, Safari or Chrome).
2. Enter your **work email** if asked. This is what you'll use to sign in.
3. Choose a password of **at least 12 characters**. A short sentence works well, for example `Winter newsletter goes out Friday`. Type it twice.
4. Select **Create my account**. You arrive on your Home page.

Your browser may offer to save the password:
- **Edge or Chrome:** select *Save*.
- **Safari:** it may suggest a strong password and save it in iCloud Keychain. Either choice is fine.

## 2. Keep the link handy

The address is the same every day (for example `https://wh-comms-pilot.fly.dev`; Maha will confirm it).

- **Windows, Edge:** press `Ctrl+D` to add a favourite. To show the favourites bar, press `Ctrl+Shift+B`.
- **Windows, Chrome:** press `Ctrl+D` to add a bookmark.
- **Mac, Safari:** press `Cmd+D` to add a bookmark, or drag the address to the Favourites bar.
- **Mac, Chrome:** press `Cmd+D`.

## 3. Sign in

Open the bookmark, enter your email and password, and select **Sign in**. You stay signed in on that computer for up to 30 days. You are signed out after 14 days without use.

On a shared computer, sign out when you finish: your name (top right) → **Sign out**.

**Forgot your password?** Ask Maha for a password reset link. It works once, for 24 hours.

## 4. Request a task

1. Select **Request a task** (on Home or Tasks).
2. Only the **title** is required. Add a short brief and, if you know it, the date you need it.
3. Optional: **Documents**. Choose up to a few files, up to 10 MB each (Word, PDF, images and so on). For bigger files, add a link to the file instead (for example a SharePoint or OneDrive link).
4. Select **Send request**.

Your request goes straight to Maha. Its status changes as Maha works on it: **Submitted → Needs clarification (if Maha has a question) → Scheduled → In progress → Awaiting approval → Complete**. The page updates by itself every few seconds while it's open, so you don't need to refresh.

If Maha asks a question, the request shows **Needs clarification**. Open it and answer under **Comments**.

## 5. Open documents

Open the request → **Documents and links** → **Open**. The file downloads with its original name:

| | Where it goes |
| --- | --- |
| Edge (Windows) | Your **Downloads** folder; a downloads panel appears at the top right |
| Chrome (Windows or Mac) | **Downloads**; shown at the top right |
| Safari (Mac) | **Downloads**; the arrow at the top right shows it |

You can open documents on your own requests. Maha and Carla can also open them. Other managers can see what Maha is working on (title, who asked, status and dates), but not your brief, comments or documents.

## 6. Calendar and meetings

- **Calendar** shows Maha's work, deadlines, events and confirmed meetings. Use **Month** / **Week** and **← Previous** / **Next →** to move around.
- **Request a meeting** (under Calendar): choose a purpose, date, time and length. You will see whether Maha is already busy. Maha confirms, declines or suggests another time. You'll see the answer under **Calendar → Meetings**.
- Times are Toronto time.

## 7. Using the keyboard

Everything works without a mouse:

- **Tab** moves to the next button or field, and **Shift+Tab** goes back.
- **Enter** opens links and buttons. **Space** ticks boxes and opens the file chooser.
- **Esc** closes a side panel or menu.
- The first **Tab** on a page offers *Skip to main content*.

**Safari only:** by default, Safari's Tab key skips links. To include them, open **Safari → Settings → Advanced** and tick **Press Tab to highlight each item on a webpage**. Or press **Option+Tab** instead of Tab.

**Windows Contrast themes** (Settings → Accessibility → Contrast themes) are supported.

## 8. If something isn't right

| What you see | What to do |
| --- | --- |
| "This link has already been used" or "has expired" | Ask Maha for a new invitation or reset link |
| "The email or password is not correct" | Check the email. After 8 wrong tries, wait 15 minutes. Ask Maha for a reset link if needed |
| "Not saved … changed … after you opened it" | Someone changed the same thing at the same time. Your typing is kept: check the latest version shown, then select the button again |
| "Could not reach the workspace server" | Check your internet connection, then try again. Nothing was saved |
| The page looks wrong or empty | Refresh (`Ctrl+R` on Windows, `Cmd+R` on Mac). Make sure your browser is up to date |
| A document won't download | Check the Downloads folder; in Edge, check the downloads panel for a "blocked" message |

Questions: ask Maha.
